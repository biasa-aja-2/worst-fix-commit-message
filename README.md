One commit message for the bug fix that made everything worse — the complaints stopped only because the fix deleted the people who were complaining.

> fix: users stopped complaining about the bug after we deleted their accounts

## Why this line

A real commit subject line, the kind a tired engineer types at the end of a bad day. The fix "worked": no more complaints about the bug. It worked because the users are gone, not because the bug is. The escalation does the whole joke in one read — no setup, no explanation, no reverting or testing-in-production cliché.

## Run it

```sh
python3 main.py
```

Writes the line (76 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
